提交原始数据和生成后的 `docs/`。GitHub Pages 从 `main` 分支的 `/docs` 发布。
日期链接为 `/robot-daily/reports/YYYY-MM-DD.html`；全部历史 JSON 保留。

网站只包含公开日报及展示代码。飞书配置和发布密钥保存在本机仓库外，不上传。
